## Overview

## Shared Patterns

**Form composition** — every modal follows the same pattern:

1. `Modal.tsx` — backdrop and card shell
2. `Form*.tsx` — react-hook-form + Zod-validated form body
3. `FormActions.tsx` — Cancel / Submit buttons with `formId` binding

**Server actions** — all data mutations live in `src/app/actions/`. Client components call them directly and use `onSuccess` callbacks to refresh local state without a page reload.
