## Key Files

| File                      | Role                                                                                                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `middleware.ts`           | Protects `/dashboard/**` — redirects to `/login` without valid JWT. Redirects authenticated users away from `/login`. |
| `src/app/actions/auth.ts` | Issues and deletes the JWT cookie. Uses `jose` for signing/verifying.                                                 |
| `src/utils/supabase.ts`   | Browser Supabase client — used by API utilities.                                                                      |
| `src/utils/api/`          | Server-side data access: employees, events, personal tasks, auth verification.                                        |
| `src/lib/utils.ts`        | `cn()` — merges Tailwind classes safely with `clsx` + `tailwind-merge`.                                               |
| `src/styles/theme.css`    | All design tokens as CSS custom properties (`--color-*`, `--animate-*`).                                              |

## Environment Variables

Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
JWT_SECRET=your_jwt_secret_key
```
